Install MESHORA

MESHORA is in testing. Here is, for each device, what really exists today, how to install it and what you should know.

Android

Test version 0.3.0-beta1 Being validated on a phone

Automatic connection to the MESHORA relay: no address to type any more. Invite someone with a QR code or a link, per-person chats, English and French interface. End-to-end encrypted messaging, signed delivery receipts, deferred sending.

Automatically verified on 26 October 2026 against the live relay (Android ↔ web exchanges, receipts, deferred delivery). The phone test is under way; version 0.2.1-beta was verified on a Google Pixel 9.

On a computer: shasum -a 256 MESHORA-0.3.0-beta1.apk. Read the certificate with apksigner verify --print-certs. Same certificate as 0.2.1-beta: installing updates it.

Install in 3 steps

  1. On the phone, tap “Download the APK”, then open the downloaded file.
  2. If Android asks, allow installs from your browser, then tap “Install”.
  3. Open MESHORA: it connects by itself. To message someone, go to Contacts → Invite someone: they scan the QR code or open the link.

This version is not on Google Play yet. Android or Play Protect may show a warning: only install MESHORA from this page or the project's GitHub page, and compare the fingerprint above.

The MESHORA relay is in pre-production, with no availability guarantee. It never sees the text of your messages. Do not rely on MESHORA in an emergency: call 112.

Bluetooth without the internet In development

A test version for testers (0.3.0-alpha) links phones over Bluetooth, without the internet. It has not yet been verified on real devices: it is meant for people who want to help us test it.

Web app

It opens in the browser, on computers and phones, and can be added to your home screen.

It connects automatically to the MESHORA relay. To exchange with someone, open the invitation link they sent you, or send yours from Settings → Invite someone.

iPhone and iPad

App planned — no version to install yet.

Meanwhile, the web app works in Safari to exchange over the internet with an invitation link. Bluetooth isn't available to web pages on iPhone: it will come with the app.

What you'll need

An invitation link

To join someone's group: a QR code or a link, opened on your device.

Bluetooth turned on

Only for the Bluetooth test version, on an Android phone or a computer with Chrome or Edge.
