Installer MESHORA

MESHORA est en phase d'essai. Voici, pour chaque appareil, ce qui existe réellement aujourd'hui, comment l'installer et ce qu'il faut savoir.

Android

Version d'essai 0.3.0-beta1 En validation sur téléphone

Connexion automatique au relais MESHORA : plus aucune adresse à saisir. Invitation d'un proche par QR code ou par lien, discussions par personne, interface en français et en anglais. Messagerie chiffrée de bout en bout, accusés de réception signés, envoi différé.

Vérifiée automatiquement le 26 octobre 2026 contre le relais réel (échanges Android ↔ web, accusés, réception différée). L'essai sur téléphone est en cours ; la version 0.2.1-beta, elle, a été vérifiée sur un Google Pixel 9.

Sur ordinateur : shasum -a 256 MESHORA-0.3.0-beta1.apk. Le certificat se lit avec apksigner verify --print-certs. Même certificat que la 0.2.1-beta : l'installation la met à jour.

Installer en 3 étapes

  1. Sur le téléphone, touchez « Télécharger l'APK », puis ouvrez le fichier téléchargé.
  2. Si Android le demande, autorisez l'installation depuis votre navigateur, puis touchez « Installer ».
  3. Ouvrez MESHORA : il se connecte tout seul. Pour écrire à quelqu'un, onglet Contacts → Inviter un proche : la personne scanne le QR code ou ouvre le lien.

Cette version n'est pas encore sur Google Play. Android ou Play Protect peut afficher un avertissement : n'installez MESHORA que depuis cette page ou la page GitHub du projet, et comparez l'empreinte ci-dessus.

Le relais MESHORA est en préproduction, sans garantie de disponibilité. Il ne voit jamais le texte de vos messages. Ne comptez pas sur MESHORA pour une urgence : appelez le 112.

Bluetooth sans Internet En développement

Une version d'essai pour testeurs (0.3.0-alpha) relie les téléphones en Bluetooth, sans Internet. Elle n'a pas encore été vérifiée sur de vrais appareils : elle est réservée aux personnes qui veulent nous aider à la tester.

Application web

Elle s'ouvre dans le navigateur, sur ordinateur comme sur téléphone, et peut être ajoutée à l'écran d'accueil.

Elle se connecte automatiquement au relais MESHORA. Pour échanger avec quelqu'un, ouvrez le lien d'invitation qu'il vous a envoyé, ou envoyez-lui le vôtre depuis Réglages → Inviter un proche.

iPhone et iPad

Application prévue — pas encore de version à installer.

En attendant, l'application web fonctionne dans Safari pour échanger par Internet avec un lien d'invitation. Le Bluetooth n'est pas accessible aux pages web sur iPhone : il viendra avec l'application.

Toutes les plateformes

Ce dont vous aurez besoin

Un téléphone ou un ordinateur

Aucun compte à créer : l'application génère votre identité sur votre appareil.

Un lien d'invitation

Pour rejoindre le groupe d'un proche : QR code ou lien, à ouvrir sur votre appareil.

Le Bluetooth activé

Seulement pour la version d'essai Bluetooth, téléphone Android ou ordinateur avec Chrome ou Edge.
