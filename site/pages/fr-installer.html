Installer MESHORA

Deux façons d'utiliser MESHORA : l'application web, pour découvrir l'interface tout de suite, et les applications natives, qui seules peuvent utiliser le Bluetooth et les réseaux proches.

Application web

Elle s'ouvre dans le navigateur et peut être ajoutée à l'écran d'accueil.

Applications natives

Les liens n'apparaissent ici qu'une fois chaque application réellement publiée et testée sur de vrais appareils.

Ce dont vous aurez besoin

Un téléphone ou un ordinateur

Aucun compte à créer. L'application génère votre identité sur votre appareil.

Le Bluetooth activé

Pour échanger avec les appareils proches quand Internet n'est pas là (applications natives).

En option : une passerelle

Un petit ordinateur chez vous (Raspberry Pi) pour relier votre réseau local à Internet et protéger votre navigation.

Pourquoi l'application web ne suffit pas

Les navigateurs, en particulier sur iPhone, ne laissent pas une page web utiliser le Bluetooth pour relier des appareils entre eux. Les fonctions sans Internet passeront donc par les applications natives.
